# HealthCover AI

A Streamlit multipage insurance-charge prediction app based on the notebook workflow.

## Run it

1. Place `insurance.csv` in this folder or upload it from the sidebar.
2. Install the packages listed in `requirements.txt`.
3. Start Streamlit with `app.py`.

The CSV must contain these columns:

`age`, `sex`, `bmi`, `children`, `smoker`, `region`, `charges`

The main page trains a linear regression model, displays analysis charts and holdout metrics, and saves each estimate. Open **Prediction history** from the sidebar to review, download, or clear saved predictions. History is stored in `prediction_history.csv` and is intentionally ignored until the first prediction is made.
